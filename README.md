# mybudgetapp

A modern, user-friendly budgeting application built with Next.js and Prisma to help you track your income, expenses, and savings with ease.

## About the Project
mybudgetapp makes budgeting simple. Log expenses, categorize spending, and see insights to stay on top of your finances.

## Features
- Add, edit, and delete income and expenses  
- Organize transactions by category  
- Dynamic dashboard for spending overview  
- Interactive charts for trends and budgeting insights  

## Tech Stack
- ![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=next.js&logoColor=white) – server-rendered React framework  
- ![Prisma](https://img.shields.io/badge/Prisma-2D3748?style=for-the-badge&logo=prisma&logoColor=white) – ORM for database access  
- ![Postgres](https://img.shields.io/badge/Postgres-316192?style=for-the-badge&logo=postgresql&logoColor=white) – database backend  
- **Tailwind CSS / daisyUI** – styling  

## Getting Started

### Prerequisites
- Node.js >= 16
- npm or yarn

### Local Setup
```bash
git clone https://github.com/woby555/mybudgetapp.git
cd mybudgetapp
npm install          # or yarn
cp .env.example .env # fill in required environment variables
npm run dev          # or yarn dev
```

Visit `http://localhost:3000` to view the app.

## Usage
1. Register or log in  
2. Navigate to the dashboard  
3. Add your income and expenses  
4. View categorized spending and trends
